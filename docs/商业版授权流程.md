# 商业版授权流程（Offline License）

> 适用：`release/commercial` 分支起的所有交付构建。
> 校验机制：Ed25519 离线签名 + 7 天有效期（默认）+ 机器指纹绑定 + 时钟回拨防护。

---

## 一、密钥与公钥关系

| 角色 | 文件 | 位置 | 是否入仓库 |
|---|---|---|---|
| 私钥（签发用） | `license_signing_ed25519.pem` | `~/.douyin_reach_keys/` | ❌ 绝不 |
| 公钥（验签用） | base64 raw 字符串 | [src/backend/license/keys.py](../src/backend/license/keys.py) | ✅ 内置 |

私钥丢失或泄漏 → 必须重新生成密钥对，并替换 `keys.py` 内的公钥常量后重新发版；旧 license 全部作废。

私钥生成（仅初次或泄漏后执行）：
```bash
python -c "from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey; \
from cryptography.hazmat.primitives import serialization; \
import base64, pathlib, os; \
d=pathlib.Path.home()/'.douyin_reach_keys'; d.mkdir(exist_ok=True); \
k=Ed25519PrivateKey.generate(); \
(d/'license_signing_ed25519.pem').write_bytes(k.private_bytes(serialization.Encoding.PEM, serialization.PrivateFormat.PKCS8, serialization.NoEncryption())); \
print(base64.b64encode(k.public_key().public_bytes(serialization.Encoding.Raw, serialization.PublicFormat.Raw)).decode())"
```

## 二、签发一个 license（开发方操作）

### 步骤 1：让客户在他的机器上跑指纹工具
客户解压交付包后，双击或命令行运行：
```bash
python tools/get_fingerprint.py
```
会打印一段 32 位十六进制字符串，例如：
```
a3f17c92b1e84d6098c5e3d12f4ab789
```
让客户把这串完整回传给你。

### 步骤 2：本地签发

#### 方式 A：图形化（推荐日常使用）
```bash
python tools/license_studio.py
```
会打开「抖音助手 · 授权码生成器」窗口：
- 填入「被授权方」「机器指纹」「有效天数」
- 点「生成激活码」→ 下方显示一长串 base64 激活码
- 点「📋 复制激活码」→ 直接发给客户
- 或点「💾 导出 license.key 文件」→ 选个保存位置生成文件，发给客户

私钥默认从 `~/.douyin_reach_keys/license_signing_ed25519.pem` 读，需要换路径可在 GUI 里浏览选择。

#### 方式 B：命令行（适合脚本批量签发）
```bash
python tools/issue_license.py \
    --licensee "示例公司" \
    --fingerprint a3f17c92b1e84d6098c5e3d12f4ab789 \
    --days 7 \
    --out license.key
```
输出会同时给出**两种交付物**：

```
已签发：F:\...\license.key
  licensee   : 示例公司
  fingerprint: a3f17c92b1e84d6098c5e3d12f4ab789
  issued_at  : 2026-04-28T10:00:00Z
  expires_at : 2026-05-05T10:00:00Z（7 天）
  license_id : 7e3b...

交付方式（任选其一）：
  方式 A · 文件：将 license.key 发给客户，客户在软件激活蒙版选「选择文件」加载。
  方式 B · 激活码：把下方一行 base64 字符串复制给客户，客户在激活蒙版选「粘贴激活码」。

---激活码 (base64)---
eyJkYXRhIjp7ImxpY2Vuc2VfaWQiOiI3ZTNiLi4uIn0sInNpZ25hdHVyZSI6Ii4uLiJ9
---------------------
```

### 步骤 3：发给客户
- **激活码方式（推荐，更友好）**：复制 `---激活码---` 之间的那一行，通过任意 IM 发给客户。
- **文件方式**：把 `license.key` 文件发给客户。
- 两种方式互通，客户在软件激活蒙版上自由切换。

## 三、客户侧使用说明

1. 双击 `抖音助手.exe`，软件会弹出**授权激活蒙版**。
2. 蒙版上：
   - 自动显示**本机指纹**，点「📋 复制」回传给软件提供方。
   - 拿到激活码 / license.key 文件后，二选一：
     - **粘贴激活码**：在文本框粘贴 base64 字符串，点"激活"。
     - **选择文件**：点"📁 选择 license.key 文件"，从硬盘选 license.key 即可。
3. 激活成功后蒙版自动消失，进入主界面。**激活码会被保存到 exe 同目录的 `data/license.key`**，下次启动无需重新激活。
4. 失败常见原因：
   - 激活码绑定的是别的机器（指纹不匹配）
   - 激活码已过期（7 天到了）→ 联系软件提供方续期
   - 复制激活码时漏字符 → 重新粘贴
5. 顶栏会持续显示"📜 授权剩余 X 天"徽章；剩 ≤2 天会变红提醒续期。

## 四、续期 / 重发

- **续期**：用 `tools/issue_license.py` 重新签发，把新激活码或新文件发给客户；客户在软件「系统设置 → 商业授权」看到当前指纹，或临近过期时直接通过激活蒙版重新激活。
- **换机器**：客户在新机器上启动软件，激活蒙版会显示新机器的指纹，把它发回签发方重签即可。
- **作废某个 license**：因为是离线方案，无法主动吊销，**只能等其自然过期**（最多 7 天）。所以 7 天有效期本身就是吊销机制。

---

## 五、状态文件 `.license_state`（无需手动维护）

软件会在 `data/.license_state` 维护一个 HMAC 签名的状态文件，用来记录"历史见过的最大时间戳"，防止用户回拨系统时间绕过过期。

- 该文件被篡改 / 删除 → 校验仍可通过（fallback 到 license 的 `issued_at`），但回拨防护会从头开始；属于安全降级，不会误杀。
- 不要让客户主动清理 `data/` 下的隐藏文件。

---

## 六、安全边界（坦诚说明）

- 这是 **离线**方案，本质防得住"复制粘贴 license 文件给同事"和"修改系统时间"，**防不住**有逆向能力的攻击者解包 exe / 替换公钥。如果未来需要更强保护，可叠加：在线激活、代码混淆 / 加壳、关键逻辑放在远程服务上。
- 7 天短周期就是为了在弱保护下也能保持商业可控：即便 license 泄漏，最坏情况一周内自动失效。
