## 12. 登录浮层 id / class

**`login-full-panel` 前缀的猜测是准确的。** 实际 id 为 `login-full-panel-{12位随机后缀}`。

完整的 DOM 层级从 `<body>` 开始：

```html
<body>
  <!-- 直接挂在 body 下 -->
  <div id="login-full-panel-tor0v69e64w0">           <!-- 最外层容器，height=0，不可见壳 -->
    <div class="ezAK2PYX vNSfRbBQ"                    <!-- 遮罩+面板容器，position:fixed; z-index:10001 -->
         style="position:fixed; z-index:10001; top:0; left:0; width:100%; height:100%;">
      <div>
        <svg id="douyin-sidebar-new-mask">…</svg>      <!-- 半透明黑色背景遮罩（可点击关闭） -->
      </div>
      <div id="login-panel-new" class="NvD4HzP9">     <!-- 白色面板本体 726×483 -->
        <div>
          <div id="douyin-login-new-id" class="douyin_login_new_class">
            <div class="aBWY4Mqx">
              <article id="douyin_login_comp_flat_panel" class="m6l1QidV">
                <!-- 登录内容区 -->
              </article>
            </div>
          </div>
        </div>
      </div>
    </div>
  </div>
</body>
```

**关键 id/class 汇总：**

| 元素 | id | class | 说明 |
|------|-----|-------|------|
| 最外壳 | `login-full-panel-{随机12位}` | （无） | 直接挂在 body 下，本身 height=0 |
| 遮罩容器 | — | `ezAK2PYX vNSfRbBQ` | `position:fixed; z-index:10001` |
| 背景蒙层 | `douyin-sidebar-new-mask` | — | `<svg>` 半透明黑色，可点击关闭 |
| 面板本体 | `login-panel-new` | `NvD4HzP9` | 白色弹窗 |
| 登录组件根 | `douyin-login-new-id` | `douyin_login_new_class` | |
| 内容区 | `douyin_login_comp_flat_panel` | `m6l1QidV` | `<article>` 标签 |

> 选择器建议：用 `document.querySelector('[id^="login-full-panel"]')` 匹配最外层，因为后缀是随机的。

## 关于验证码浮层（#13 补充）

当前未触发风控，DOM 中不存在任何含 `captcha` 或 `verify` 的 class/id。验证码组件是完全按需加载的——只有在触发滑块/拼图验证时才会注入 DOM。如需实测 `.vc-captcha-verify-visibility` 是否为真实 class，需要在高频操作（如快速刷新、批量请求）触发风控后才能观察到。
